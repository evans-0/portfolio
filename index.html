Field Work

Experience

Research & Development Intern
Digital University Kerala, Thiruvananthapuram · On-site
July 2026 – Present

Building and running the backend for an IoT cold-chain monitoring system that tracks milk tankers, vans and freezers.

  • Migrated the monitoring dashboard from Google Sheets to PostgreSQL on AWS RDS and deployed it on AWS EC2 (Flask, nginx, gunicorn), with 85 API/OTA endpoints, 4 role-based portals and Web Push alerts.
  • Designed the device protocol: per-device API keys, over-the-air config and firmware updates for 3 device types, and an on-disk queue that keeps readings during database outages and replays them automatically.
  • Load-tested the live server at ~250 req/s with 0 errors over 36K requests on 2 vCPU / 1 GB, using a per-role response cache and an optional shared Valkey cache.
  • Hardened the public server against constant bot scanning (nginx allowlist, rate limits, fail2ban, strict CSP, auto-renewing HTTPS), with role-based access and 669 automated tests.
  • Reduced false alerts by inferring device state from sensor data: detecting freezers switched off on purpose and telling empty tanker compartments from loaded ones.
